# MycoAI Retrieval Frontend

React frontend for scientist-facing retrieval, dataset, and indexing workflows in the MycoAI platform.

## Stack

- React 19
- Vite
- Tailwind CSS v4
- shadcn/ui
- TypeScript
- ESLint
- Prettier

## Commands

```bash
npm install
npm run dev
npm run lint
npm run format
npm run format:check
npm run typecheck
npm run build
```

## UI Setup

- Tailwind CSS v4 via `@tailwindcss/vite`
- shadcn/ui initialized with the `radix-nova` preset
- `@/*` alias mapped to `src/*`
